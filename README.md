# Numerical Methods in C++

A collection of numerical analysis algorithms implemented in modern C++. This repository contains computational methods for finding roots of polynomial functions.

## Implemented Algorithms

* **Bisection Method** (`bisection.cpp`)
* **Newton-Raphson Method** (`newton_raphson.cpp`)
* **Secant Method** (`secant.cpp`)
* **False Position Method** (`false_position.cpp`)
* **Birge-Vieta Method** (`birge_vieta.cpp`)

## How to Compile and Run

You can compile any of these files using a standard C++ compiler like GCC. For example, to run the Bisection method:

```bash
g++ bisection.cpp -o bisection
./bisection.exe
